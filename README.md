# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM
# AIM:
To draw the UML diagram for Student Online Exam Registration System.

# SRS (Procedure):
Step 1: Problem Identification
The main problem is to develop an automated system that allows students to register for exams easily and efficiently.

Step 2: Requirement Analysis
Identify the users involved in the system:

-Student
-Admin
-Mentor
-Organisation

Functional requirements:
Student registration and login
View available exams
Check exam details
Select and register for exams
Make exam fee payments
Confirm exam registration
Admin manages students and exams
Exam coordinator manages exam information

Step 3: System Design
Design the Student Online Exam Registration System using UML diagrams:

Use Case Diagram
Class Diagram
Activity Diagram
Sequence Diagram
Communication Diagram
Package Diagram

Step 4: System Interaction
Represent the interaction between the Student, Admin, Payment Gateway, Exam Coordinator, and the Exam Registration System.
